SS Mocap - Gestures Mocap Pack

This package features 41 different motion-captured animations for use on bipedal humanoid characters in FBX format. Each Animation performance is directed towards a gesture, movement or reaction a character may give during a conversation or cut-scene. 

Each of the FBX animations can be found and edited in the /Animations folder. They are pre-configured for humanoid characters and are seperated by different moods or actions.

Each performance varies in length, and can be edited and re-mixed by you to create more complex animation sequences.

The /Demo folder contains a demo scene, demo character and demo timeline showcasing how the animations can be used to build out a conversation sequence between two characters.
