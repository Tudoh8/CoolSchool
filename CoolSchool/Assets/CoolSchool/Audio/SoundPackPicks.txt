# CoolSchool sound picks: which imported clips play for each cue.
# Read by Tools/import-audio-clips.py (copies the clips out of the Asset Store packages)
# and by CoolSchool > Audio > Apply Sound Pack Picks (fills SoundLibrary.asset).
#
# One cue per line, tab separated:  cue  volume  pitchMin  pitchMax  clips
# Empty volume/pitch = keep the default (1, 0.95..1.05). Clips are separated by " | ".
# A clip starts with a pack key; the rest is its path inside that pack:
#   PM   = Phantom Magic Sounds        (Assets/Phantom Magic/)
#   AR   = Action RPG SFX Pack v2      (Assets/Action RPG SFX V2/)
#   ENV  = Environment Sounds Pack     (Assets/Environment Sounds/)
#   BES  = Bestiary Monster Bundle     (Assets/BestiaryMonsterBundle/)
#   MON  = Monster Sounds Pack         (Assets/Monster Sounds Pack/)
#   FEEL = Feel                        (Assets/Feel/)
#   GUI  = Ultimate Clean GUI Pack     (Assets/UltimateCleanGUIPack/Common/Sounds/)
#   POLY = already in the project      (Assets/polyperfect/Low Poly Animated Animals/Sounds/)
# Imported clips land in Assets/Imported/Audio/<PackFolder>/<path inside the pack>.
# Picks were made from file names; audition them and swap any that sound wrong.
